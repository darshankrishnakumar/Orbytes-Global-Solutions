# Security Policy

## Supported Versions

The current `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within this application, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email describing the vulnerability, affected components, and steps to reproduce to `darshankrishnakumar@gmail.com` or the repository maintainer.
3. We will acknowledge receipt within 48 hours and coordinate remediation before public disclosure.
